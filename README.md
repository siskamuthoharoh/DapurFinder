\# DapurFinder



DapurFinder adalah proyek mata kuliah Sistem Temu Kembali Informasi (STKI) yang bertujuan membangun mesin pencarian resep masakan Indonesia.



\## Tujuan Proyek



\- Membantu pengguna menemukan resep berdasarkan kata kunci.

\- Menerapkan TF-IDF untuk merepresentasikan teks resep.

\- Menggunakan Cosine Similarity untuk mengurutkan hasil berdasarkan kemiripan dengan pencarian pengguna.

\- Menguji dan mengevaluasi hasil pencarian.



\## Informasi Dataset



Dataset berisi resep dengan informasi judul, bahan, langkah memasak, jumlah suka, URL, dan kategori masakan.



Dataset disimpan secara lokal dan tidak diunggah ke repositori GitHub.



\## Teknologi



\- Python

\- Jupyter Notebook

\- pandas

\- scikit-learn

\- Git dan GitHub



\## Metode Pencarian



Metode awal yang direncanakan adalah TF-IDF dan Cosine Similarity. Metode akan diuji menggunakan beberapa kata kunci untuk melihat relevansi resep yang ditemukan.
